Un lenguaje pequeño y relajado

Snow nació del entusiasmo por experimentar con intérpretes en Go. No compite con nadie: su meta es que levantar un microservicio o consultar una API sea tan simple como escribir 5 líneas limpias.

Sin llaves {}, sin puntos y coma ;, con HTTP integrado, almacenamiento en disco y herramientas de terminal.

Hecho por JDVA0 · Diversión y experimentación libre

using api

# Servidor web en 5 líneas
api.cors()

api.get("/", fn(req):
    api.json({
        mensaje: "Hola desde Snow!",
        autor: "JDVA0",
        modo: "experimentación"
    })
)

api.serve(8080)
