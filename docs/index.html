Un lenguaje pequeño, plano y relajado

Snow nació del entusiasmo por experimentar y crear un intérprete funcional en Go. No busca ser revolucionario ni competir con otros: su meta es que levantar un microservicio o consultar una API sea tan simple como escribir 5 líneas limpias.

Sin llaves {}, sin puntos y coma ;, con cliente y servidor HTTP integrados, almacenamiento en disco y herramientas de terminal.

Hecho por JDVA0 · Diversión y experimentación libre

using api

# Servidor web en 5 líneas
api.cors()

api.get("/", fn(req):
    api.json({
        mensaje: "Hola desde Snow!",
        autor: "JDVA0",
        modo: "experimentación"
    })
)

api.serve(8080)

Servidor HTTP Nativo

El módulo api permite definir rutas GET, POST, PUT, DELETE, habilitar CORS y responder JSON en milisegundos sin frameworks pesados.

Ver módulo api →

Cliente HTTP (using http)

Consume APIs externas directamente: http.get(), http.post() con serialización automática de JSON y cabeceras sin dependencias.

Ver módulo http →

Persistencia KV (using db)

Almacén clave-valor embebido persistido a disco en formato JSON atómico para que tus servicios guarden estado con cero configuración.

Ver módulo db →
