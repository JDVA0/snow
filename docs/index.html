Snow

Snow es un lenguaje de programación interpretado, ligero y minimalista, desarrollado en Go. Su sintaxis es limpia y directa: sin llaves {} y sin puntos y coma ;.

Hecho por JDVA0 · Un proyecto por diversión y experimentación. Para prototipar APIs web y scripts sin complicaciones.

$ git clone https://github.com/JDVA0/snow && cd snow && go build ./cmd/snowman

Primeros pasos
Instalación

Instrucciones para compilar desde el código fuente o usar el binario snowman.

REPL interactivo

Consola interactiva con historial de comandos, autocompletado y bloques indentados.

Tu primer script

API en 5 líneas

Levanta un servidor HTTP funcional con endpoints y respuesta JSON en segundos.

El lenguaje
Sintaxis e indentación

Bloques basados en indentación consistente de 2 o 4 espacios sin llaves.

Tipos y operadores

Enteros, flotantes, cadenas, booleanos, listas, mapas y operador ??.

Funciones y closures

Definición con fn, retorno de valores y soporte para funciones de primera clase.

F-strings e interpolación

Interpolación limpia de variables y expresiones usando la sintaxis f"...".

Módulos integrados
api — Servidor HTTP

Rutas GET, POST, PUT, DELETE, soporte CORS nativo y manejo JSON automático.

http — Cliente HTTP

Consumo de APIs REST externas con http.get() y http.post().

db — Almacén clave-valor

Persistencia local en disco embebida sin necesidad de bases de datos externas.

sys & fs — Sistema y archivos

Lectura y escritura segura de archivos, variables de entorno y utilidades del sistema.

CLI Toolkit
cli.box y cli.table

Cajas y tablas formateadas con cálculo exacto de ancho dinámico para la terminal.

Colores y estilos ANSI

Formateo de texto en consola sin dependencias complejas ni configuración.

Parseo de argumentos

cli.parse() para construir utilidades de línea de comandos con flags y comandos.

Prompts interactivos

Pide datos al usuario con cli.ask() o confirmaciones con cli.confirm().

Referencia rápida
Funciones nativas

print, len, str, int, range, keys, values...

Manejo de errores

Reporte claro de errores sintácticos y de ejecución con número de línea.
