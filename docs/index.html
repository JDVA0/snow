Snow

Snow es un lenguaje de programación pequeño e interpretado, hecho en Go. Su sintaxis es limpia y sin ruido: sin llaves {}, sin puntos y coma ;.

Hecho por JDVA0 por diversión y experimentación. No compite con nadie — su meta es hacer que levantar una API o escribir un script sea lo más simple posible.

Compila desde el código fuente con go build ./cmd/snowman o descarga el binario desde GitHub.

Módulos integrados
api — Servidor HTTP

Rutas GET, POST, PUT, DELETE, CORS y respuesta JSON. Arranca un servidor en segundos.

http — Cliente HTTP

Consume APIs externas con http.get() y http.post(). JSON automático.

db — Persistencia KV

Almacén clave-valor embebido, persistido a disco. Sin bases de datos externas.

sys / fs — Sistema

Acceso a archivos, variables de entorno y operaciones del sistema operativo.

CLI Toolkit
