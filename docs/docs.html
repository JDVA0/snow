Snow

Snow es un lenguaje de programación simple y plano, diseñado específicamente para facilitar la creación de APIs web y scripts de sistema sin dependencias externas complejas.

Proyecto creado por JDVA0 con asistencia de inteligencia artificial. Hecho por diversión y para experimentar, totalmente libre y abierto para que cualquier persona en el mundo lo use, aprenda y cree APIs sin complicaciones.

Puntos clave

  • Indentación por espacios: se usan 4 espacios para definir bloques. No hay llaves {} para delimitar código ni puntos y comas ; al final de línea.
  • Servidor HTTP nativo: el módulo api permite levantar servidores web, definir rutas (GET, POST, PUT, DELETE, PATCH), habilitar CORS y retornar JSON con funciones sencillas.
  • Acceso al sistema y archivos: los módulos sys y fs permiten ejecutar comandos del sistema, leer variables de entorno, gestionar procesos y manipular archivos en disco.
  • Herramientas de terminal: el módulo cli incluye analizador de argumentos, formateo de tablas y cajas de texto.

Instalación

El módulo oficial en Go es github.com/JDVA0/snow.

1. Descargar el módulo como paquete en Go

Si deseas incrustar el intérprete de Snow dentro de una aplicación en Go:

go get github.com/JDVA0/snow

2. Compilar e instalar el ejecutable snowman

Para ejecutar programas Snow directamente en tu máquina:

git clone https://github.com/JDVA0/snow.git
cd snow
go build -o snowman ./cmd/snowman
sudo mv snowman /usr/local/bin/

Sintaxis e Indentación

Snow es un lenguaje limpio. Las líneas se ejecutan secuencialmente de arriba hacia abajo.

Comentarios

Todo lo que sigue a una almohadilla # hasta el final de la línea se ignora:

# Esto es un comentario
x = 10 # También se puede comentar al final de una línea

Regla de Indentación (Bloques)

Cuando abres un bloque de código (con if, elif, else, for, while o fn), la línea debe terminar con dos puntos :. Todas las líneas que formen parte de ese bloque deben comenzar con 4 espacios de indentación:

valor = 15

if valor > 10:
    print("El valor es mayor que 10")
    print("Esta línea también pertenece al bloque if")

print("Esta línea ya está fuera del bloque porque no tiene espacios")

# Variables simples
nombre = "Snow"

total = 10

F-Strings, Operador Elvis (??) y Cadenas Multilínea

Snow soporta interpolación directa de expresiones, valor por defecto para nulos y literales de texto multilínea:

# 1. F-Strings (interpolacion de expresiones)
usuario = "Julian"
edad = 25
print(f"Hola {usuario}, tienes {edad} años. En 5 años tendrás {edad + 5}.")

# 2. Operador Elvis / Nullish coalescing (??)
nombre_param = nil
nombre_final = nombre_param ?? "invitado"
print(f"Bienvenido, {nombre_final}")

# 3. Cadenas multilínea con triples comillas
sql = """SELECT id, nombre, email
FROM usuarios
WHERE activo = true
ORDER BY id DESC"""
print(sql)

Control de Flujo

1. Condicional if / elif / else

estado = 200

if estado == 200:
    print("Respuesta correcta (OK)")
elif estado == 404:
    print("Recurso no encontrado")
elif estado >= 500:
    print("Error interno del servidor")
else:
    print("Otro estado:", estado)

2. Bucle for

Recorre los elementos de una lista:

rutas = ["/inicio", "/usuarios", "/contacto"]

for r in rutas:
    print("Registrando ruta:", r)

3. Bucle while con break y continue

cuenta = 0
while cuenta < 10:
    cuenta += 1
    if cuenta == 3:
        continue
    if cuenta == 6:
        break
    print("Numero:", cuenta)

Funciones y Lambdas

1. Funciones estándar con bloques (fn)

Se definen con la palabra clave fn, nombre, paréntesis con argumentos separados por coma, dos puntos y bloque indentado:

fn calcular_iva(precio, tasa):
    iva = precio * tasa
    total = precio + iva
    return total

factura = calcular_iva(100, 0.16)
print("Total con IVA:", factura)  # 116.0

2. Funciones lambda en una línea

Para expresiones cortas y pasar como argumento a otras funciones:

# Asignada a variable
cuadrado = fn(x): x * x
print(cuadrado(6))   # 36

# Usada como argumento de transformacion
numeros = [1, 2, 3, 4]
dobles = map(fn(n): n * 2, numeros)
print(dobles)        # [2, 4, 6, 8]

mayores = filter(fn(n): n > 2, numeros)
print(mayores)       # [3, 4]

Funciones Nativas

Están siempre disponibles en el intérprete sin necesidad de importar ningún módulo:

Función Descripción Ejemplo
print(...)Escribe argumentos en stdout separados por espacio y agrega salto de línea.print("Hola", 42)
len(x)Devuelve la cantidad de elementos en cadena, lista o diccionario.len("Snow") # 4
str(x), int(x), float(x)Conversión de tipo explícita.n = int("123")
type(x)Devuelve el nombre del tipo: "int", "float", "str", "bool", "list", "dict", "nil".type(10) # "int"
append(lista, v)Agrega un valor al final de la lista y devuelve la lista.l = append(l, "nuevo")
split(s, sep)Divide una cadena en una lista de subcadenas según el separador.split("a,b,c", ",")
join(lista, sep)Une los elementos de una lista de cadenas usando el separador dado.join(["a", "b"], "-")
trim(s)Elimina espacios en blanco al inicio y al final de la cadena.trim(" hola ")
upper(s) / lower(s)Convierte caracteres a mayúsculas o minúsculas.upper("snow") # "SNOW"
contains(a, b)Comprueba si una cadena contiene a otra o si un elemento está en una lista.contains("lenguaje", "guaje")

using api

El módulo api permite crear servidores HTTP, definir rutas y responder peticiones web sin ninguna librería externa.

Métodos disponibles

Método Descripción y Ejemplo
api.cors([origen])Habilita CORS para permitir peticiones desde navegadores. Por defecto permite "*". Responde automáticamente las peticiones OPTIONS preflight con código 204.
api.get(ruta, handler)Registra una ruta GET. Admite parámetros dinámicos con dos puntos: api.get("/usuarios/:id", handler).
api.post(ruta, handler)Registra una ruta POST para recepción de datos: api.post("/crear", handler).
api.put(ruta, handler)Registra una ruta PUT (actualización total).
api.patch(ruta, handler)Registra una ruta PATCH (actualización parcial).
api.delete(ruta, handler)Registra una ruta DELETE.
api.all(ruta, handler)Registra una ruta para cualquier método HTTP.
api.use(middleware_fn)Registra un middleware que se ejecuta en cada petición antes de las rutas. Si devuelve una respuesta, corta el flujo. Si devuelve nil, continúa al handler.
api.static(prefijo, carpeta)Sirve archivos estáticos: api.static("/archivos", "./public").
api.serve(puerto)Bloquea el proceso y pone a escuchar el servidor HTTP en el puerto indicado: api.serve(8080).
api.json(datos, [codigo])Genera una respuesta con cabecera Content-Type: application/json y código de estado opcional (200 por defecto).
api.text(texto, [codigo])Genera una respuesta en texto plano (text/plain).
api.html(html, [codigo])Genera una respuesta en HTML (text/html).
api.redirect(url, [codigo])Redirige a otra URL (código 302 por defecto).

Estructura del objeto req

Cada función de ruta recibe un único argumento con la información de la solicitud:

Propiedad Tipo Descripción
req.methodstrMétodo de la solicitud: "GET", "POST", "PUT", etc.
req.pathstrRuta solicitada: "/usuarios/42".
req.querydictParámetros de la URL: ?orden=precio&limite=5 produce req.query.orden ("precio") y req.query.limite ("5").
req.paramsdictVariables capturadas en la ruta: en /usuarios/:id, req.params.id contiene el valor enviado.
req.headersdictCabeceras HTTP enviadas por el cliente en minúsculas: req.headers["authorization"].
req.bodystrCuerpo crudo de la petición como texto.
req.jsondict o listCuerpo decodificado automáticamente si el cliente envió JSON válido.

Ejemplo completo de servidor API

using api

# 1. Habilitar CORS
api.cors()

# 2. Middleware de registro
fn registrar(req):
    print("[" + req.method + "] " + req.path)
    return nil

api.use(registrar)

# 3. Ruta GET con query string (?buscar=algo)
fn buscar(req):
    termino = req.query.buscar
    if termino == nil:
        termino = "todos"
    return api.json({resultado: termino, total: 1})

api.get("/buscar", buscar)

# 4. Ruta GET con parametro dinámico (:id)
fn ver_item(req):
    id = req.params.id
    return api.json({id: id, activo: true})

api.get("/items/:id", ver_item)

# 5. Ruta POST con recepcion de JSON
fn guardar(req):
    datos = req.json
    return api.json({guardado: true, datos: datos}, 201)

api.post("/items", guardar)

# 6. Iniciar servidor en el puerto 8080
api.serve(8080)

using http

Cliente HTTP integrado para consumir APIs REST externas sin depender de herramientas externas como curl ni librerías adicionales.

Función Descripción
http.get(url, [headers])Realiza una petición HTTP GET. Devuelve un objeto con status, ok, body, headers, json() y text().
http.post(url, [body], [headers])Realiza una petición POST. Si body es un diccionario o lista, se serializa automáticamente a JSON y se envía el encabezado application/json.
http.put / http.patch / http.deleteMétodos PUT, PATCH y DELETE con las mismas facilidades de serialización de cuerpo y encabezados personalizados.

Ejemplo de consumo de API

using http

# Consumir un servicio externo
resp = http.get("https://httpbin.org/get")
if resp.ok:
    datos = resp.json()
    print(f"IP de origen: {datos['origin']}")
    print(f"Estado HTTP: {resp.status}")
else:
    print(f"Error en peticion: {resp.status}")

# Enviar datos con POST en formato JSON
nuevo_usuario = {nombre: "Julian", rol: "desarrollador"}
res_post = http.post("https://httpbin.org/post", nuevo_usuario)
if res_post.ok:
    print("Respuesta del servidor:", res_post.json())

using db

Almacén clave-valor embebido persistente en disco (JSON estructurado) con escritura atómica segura, ideal para APIs y microservicios ligeros.

Método Descripción
db.open(archivo)Abre o crea un almacén de datos en la ruta indicada. Devuelve un objeto store.
store.set(clave, valor)Guarda un valor (número, cadena, booleano, lista o diccionario) asociado a la clave.
store.get(clave, [por_defecto])Obtiene el valor de una clave. Si no existe, retorna por_defecto o nil.
store.has(clave)Devuelve true si la clave existe en el almacén.
store.keys()Devuelve una lista con todas las claves registradas.
store.delete(clave)Elimina una clave del almacén.
store.all()Devuelve una copia del diccionario completo de datos.
store.save()Persiste todos los datos en disco de forma atómica en formato JSON.

Ejemplo de uso de db

using db

almacen = db.open("usuarios.json")

# Guardar registros
almacen.set("u_101", {nombre: "Julian", activo: true, nivel: 5})
almacen.save()

# Consultar
usuario = almacen.get("u_101")
print(f"Usuario cargado: {usuario.nombre}")

# Clave no encontrada con valor por defecto
rol = almacen.get("rol_invalido", "visitante")
print(f"Rol asignado: {rol}")

using sys

Permite consultar el entorno de ejecución, ejecutar comandos externos y controlar el proceso.

Propiedad / Función Descripción y Ejemplo
sys.platformSistema operativo: "linux", "darwin" (macOS) o "windows".

Ejemplo de uso de fs

Ejemplo Completo 1: API REST CRUD en Memoria

Un servicio web completo con listado, consulta por ID y creación con persistencia en lista:

using api
using cli

# Habilitar CORS para clientes web
api.cors()

# Base de datos simulada en memoria
usuarios = [
    {id: 1, nombre: "Ana", rol: "admin"},
    {id: 2, nombre: "Carlos", rol: "editor"}
]

# Middleware para registrar cada llamada
fn log_peticion(req):
    cli.info(req.method + " " + req.path)
    return nil

api.use(log_peticion)

# 1. Listar todos los usuarios
fn listar_usuarios(req):
    return api.json(usuarios)

api.get("/usuarios", listar_usuarios)

# 2. Obtener un usuario por su ID
fn obtener_usuario(req):
    id_buscado = int(req.params.id)
    for u in usuarios:
        if u.id == id_buscado:
            return api.json(u)
    return api.json({error: "Usuario no encontrado"}, 404)

api.get("/usuarios/:id", obtener_usuario)

# 3. Crear un nuevo usuario (POST)
fn crear_usuario(req):
    nuevo = req.json
    if nuevo == nil or nuevo.nombre == nil:
        return api.json({error: "Datos invalidos: se requiere 'nombre'"}, 400)

    nuevo.id = len(usuarios) + 1
    usuarios = append(usuarios, nuevo)
    return api.json(nuevo, 201)

api.post("/usuarios", crear_usuario)

# Iniciar servidor
cli.info("Servidor escuchando en http://localhost:8080")
api.serve(8080)

Ejemplo Completo 2: Herramienta de Diagnóstico de Sistema

Un programa de línea de comandos que acepta flags y analiza el estado de la computadora:

using cli
using sys
using fs

cli.box("SNOW DIAGNOSTICO", "Herramienta de diagnostico y estado")

parsed = cli.parse()
flags = parsed.flags
args = parsed.args

# Mostrar tabla de sistema
cabeceras = ["PROPIEDAD", "VALOR"]
filas = [
    ["Sistema Operativo", sys.platform],
    ["Arquitectura", sys.arch],
    ["ID de Proceso (PID)", str(sys.pid)],
    ["Directorio de Trabajo", sys.cwd()],
    ["Fecha y Hora", sys.now()]
]
cli.table(cabeceras, filas)

# Si el usuario pasa la bandera --archivos, listar directorio
if flags.archivos == true:
    elementos = fs.list(".")
    cli.info("Archivos en el directorio (" + str(len(elementos)) + "):")
    filas_archivos = []
    for elem in elementos:
        tipo = "archivo"
        if fs.is_dir(elem):
            tipo = "directorio"
        filas_archivos = append(filas_archivos, [elem, tipo])
    cli.table(["NOMBRE", "TIPO"], filas_archivos)

cli.success("Diagnostico finalizado con exito.")

Ejemplo Completo 3: Lector y Procesador de Archivos

Script que procesa líneas de texto, cuenta registros y exporta resultados limpios:

using fs
using cli

archivo_origen = "registro.txt"

# Crear archivo de prueba si no existe
if not fs.exists(archivo_origen):
    fs.write(archivo_origen, "servidor_1,activo\nservidor_2,inactivo\nservidor_3,activo\n")

contenido = fs.read(archivo_origen)
lineas = split(trim(contenido), "\n")

cli.info("Total de lineas encontradas: " + str(len(lineas)))

filas = []
activos = 0

for l in lineas:
    partes = split(l, ",")
    if len(partes) == 2:
        srv = partes[0]
        estado = partes[1]
        if estado == "activo":
            activos += 1
        filas = append(filas, [srv, estado])

cli.table(["SERVIDOR", "ESTADO"], filas)
cli.info("Servidores activos: " + str(activos))
